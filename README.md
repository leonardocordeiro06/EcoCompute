# EcoCompute

Projeto da disciplina de Internet e Sociedade sobre o consumo de energia e água por trás da inteligência artificial.

O site usa HTML, CSS e JavaScript. A calculadora compara o uso de IA com quatro perfis fictícios. Os pontos servem para comparar os perfis e não correspondem a medidas de energia ou água.

## Como abrir

Baixe e extraia os arquivos do repositório. Depois abra o `index.html` no navegador.

Para publicar no GitHub Pages, vá a **Settings → Pages** e selecione **Deploy from a branch**, a branch `main` e a pasta `/ (root)`.
